# NeonForge OS — Autonomous Digital Asset Synthesizer & Commerce Engine

NeonForge OS is a full-stack digital commerce platform and multi-agent synthesis engine built for autonomous product generation, dynamic asset compilation, SHA-256 cryptographic license issuance, and real-time inventory vaults.

---

## ⚡ Quickstart Guide

### 1. Requirements
- **Node.js**: v22.0.0 or higher (required for native `node:sqlite` engine with WAL journaling)
- **npm** or **bun** / **yarn**

### 2. Installation
Clone or extract the repository, then install project dependencies:
```bash
npm install
```

### 3. Environment Configuration (Optional)
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
NeonForge OS features server-side AI generation powered by `@google/genai`. If you have a Gemini API key:
```env
GEMINI_API_KEY=your_gemini_api_key_here
PORT=3000
```
*Note: The engine includes robust algorithmic fallbacks and works offline/without an API key.*

### 4. Running the Dev Server
Launch the unified full-stack Express + Vite development environment:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
